# Kelen Lens Lab — لێنسی سینەمایی بۆ Blender

زیادکراوێک بۆ Blender کە لێنسی سینەمایی دەخاتە سەر کامێراکەت: بۆکەی سووڕاوە، ئەنامۆرفیک، پێتزڤاڵ، پریزم و خاڵی خەون. لەگەڵیدا کاری کۆتایی فیلمیش دەکات: گرێن، هالەیشن، درەوشانەوە، جیابوونەوەی ڕەنگ و تاریکی گۆشەکان.

> پێویستی بە **Blender 5.0 یان نوێتر** و ڕێندەری **Cycles** هەیە.

## دامەزراندن

1. فایلی `kelen_lens_lab.py` دابگرە.
2. لە Blender بڕۆ بۆ: **Edit → Preferences → Add-ons**.
3. لە سەرەوەی لای ڕاست، لیستەی ▾ بکەرەوە و **Install from Disk…** هەڵبژێرە، پاشان فایلەکە هەڵبژێرە.
4. چوارگۆشەی **Kelen Lens Lab** چالاک بکە.

## بەکارهێنان

1. لە پەنجەرەی 3D کلیلی **N** دابگرە و تابی **Lens** بکەرەوە.
2. لێنسێک هەڵبژێرە:

| لێنس | چی دەکات |
|---|---|
| Clean | لێنسی نوێی ڕوون، بۆکەی خڕ |
| Anamorphic | بۆکەی هێلکەیی و هێڵی شینی ئاسۆیی، شێوازی فیلمی سینەمایی |
| Swirl | بۆکەی سووڕاوە، وەک لێنسی کۆنی Helios |
| Petzval Vortex | سووڕانەوەی بەهێز، لێوارەکان دەتوێنەوە |
| Dream Field | ناوەڕاست ڕوون و لێوارەکان تەماوی |
| Fisheye | چەمانەوەی بەهێزی چاوی ماسی |
| Prism Halo | دووبارەبوونەوەی درەوشاوە لە لێوارەکاندا، وەک پریزمی شووشە |
| Prism Kaleido | ڕەنگدانەوەی کالیدۆسکۆپی |
| Dream Spot | خاڵێکی ڕووناک لە ناوەڕاستدا، ئەوانی تر دوور دەکەونەوە |

3. لە **Focus** شتێک هەڵبژێرە کە ڕوون بێت (بۆ نموونە سەری کارەکتەرەکە)، و **F-Stop** دابنێ (ژمارەی کەمتر واتە پشتەوەی تەماویتر).
4. سلایدەرەکانی **Finishing** ڕێک بخە، پاشان **Apply Lens** دابگرە.
5. ڕێندەر بکە (F12).

**تێبینی:** دەقی ناو Blender بە ئینگلیزییە، چونکە Blender نووسینی کوردی و عەرەبی بە دروستی پیشان نادات (پیتەکان جیا جیا و پێچەوانە دەردەکەون).

## نموونە

`night_lantern_scene.py` دیمەنی «فانووس» دروست دەکات: ژنێکی کورد بە فانووسێکەوە لەناو دەریاچەیەکی مانگە شەودا، و گوندێکی هەورامی لە دوورەوە دەدرەوشێتەوە. ئەم دیمەنە هەموو بەشەکانی زیادکراوەکە بەکار دەهێنێت.

```
blender -b -P night_lantern_scene.py -- out.png
```
