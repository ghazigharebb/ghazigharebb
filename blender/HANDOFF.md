# Blender پرۆژەی غازی — پوختەی تەواوی گفتوگۆ (Handoff)

> بۆ هەر Claude ـیەک کە ئەم فایلە دەیخوێنێتەوە: ئەمە پوختەی هەموو ئەوەیە کە لەگەڵ بەکارهێنەر (غازی، ناوی کەناڵ: وەستا غەریب) کراوە.
> زمانی وەڵام: **کوردی سۆرانی** بە شێوەی سروشتی، مەگەر داوای زمانێکی تر بکات.
> ڕەفتار: ڕاستگۆ بە، چاکسازی بکە پێش ناردن، هەرگیز ئەنجامێکی خراپ وەک "تەواو" مەنێرە. بەکارهێنەر وێنەی تاقیکاری نایەوێت، تەنها وێنەی کۆتایی.

## 1. ژینگەی کار (cloud container)
- Blender کار دەکات بە **`bpy` 4.5.4 LTS** لە venv ـی Python 3.11 (`pip install bpy==4.5.4`). `blender.org` بلۆکە، بەڵام PyPI و GitHub کارن.
- **ئامرازەکان:** Cycles (CPU)، Mantaflow، Geometry Nodes، OIDN denoiser، ffmpeg، OpenCV (venv ـی جیا، چونکە numpy ی ناکۆکە)، Pillow.
- **EEVEE** پێویستی بە `libEGL` هەیە (`apt-get install libegl1 libegl-mesa0 libgl1-mesa-dri libgbm1`) و بە CPU زۆر هێواشە. Cycles باشترە.
- **سنووری:** 4 CPU، 15GB RAM، **GPU نییە**. Poly Haven، Sketchfab، CGTrader، Hugging Face، JangaFX، blender.org: **بلۆکن**. GitHub و PyPI کار دەکەن.
- Blender ـی ناو `bpy` ئاگادارکەرەوەی `EGL` دەدات بێ کێشە؛ شتێکی ئاسایییە.
- کۆنتەینەرەکە کاتییە: هەموو شتێک دەبێت لە **GitHub** پاشەکەوت بکرێت. Stop hook داوا دەکات هەموو فایلێک commit و push بکرێت. لق: `ccr-86c86c21-qwermv`.
- فۆنتی کوردی: **Vazirmatn** لە GitHub داگیراوە (OFL). Blender خۆی کوردی ڕاست نانووسێت؛ تێکستی کوردی پێشتر بە Pillow+RAQM (`language="ckb"`, `direction="rtl"`) دەکرێت بە تێکستچەر.

### فایلە سەرەکییەکان
- `generator_web/scene.py` دیمەنی تەواو (`-- render W H samples out.png`)؛ `post.py` فینیشی فیلم؛ `make_signs.py` تابلۆی کوردی؛ `merge_patches.py`؛ `generator_web.blend`.
- `rider/standing.py` (`-- sim` یەکەم cloth sim دەکات و `work/cloak_sim.obj` دروست دەکات، پاشان `-- render`)؛ `post.py`؛ `spear_bearer.blend`.
- هەردوو پرۆژە: `.gitignore` ـی `work/` و `out/`.

## 3. وانە تەکنیکییەکان (گرنگ بۆ بەردەوامبوون)
- **باران بە 3D particles** پەڵەی سپی لەسەر دیوارەکان دروست دەکات؛ باران لە post بکە (streaks کە تەنها لە بەرامبەر ڕووناکیدا دیارن).
- **پەنجەرەی boolean** پێویستە cutter ـەکەی نزیکەی 0.62m قووڵ بێت و ڕووناکی ناوەوە 0.26m لەپشت دیوارەوە.
- **ڕەنگی AgX** پڕتەقاڵی دەکاتە پەمەیی؛ `Filmic` بۆ ڕەنگی گەرم باشترە.
- **DOF** لە ماکرۆی ناوەوەی پڕتەقاڵدا هەموو شتێک لێڵ دەکات؛ لە ناوەوە بیکوژێنەوە.
- **Cloth sim:** `pin` تەنها بەند و خوار سەرەوەی کڵاو بکە، نەک تاجی سەرەوە (دەبێتە پیاوی بێ سەر). سەر پێویستە ellipsoid بێت.
- **Light linking** بۆ ئەوەی گڵۆپی سەری ڕم تیغەکە بە سپی نەسووتێنێت.
- **16-bit PNG** ی تاریک banding ی نییە؛ ئەگەر لە شاشەدا دیار بوو، لە 8-bit بە dither بیگۆڕە.
- Python 3.11 venv: `bvenv` بۆ bpy (numpy<2)، `cvenv` بۆ OpenCV/Pillow.
- ڕێندەری دوای وێنەی گەورە: `adaptive_threshold 0.015–0.02`، `OIDN` + albedo/normal.
- کات: «تۆڕی مۆلیدە» 4K/256 samples = 1ک25خ؛ «سوار» 2160×2700/192 = 20خ.

## 4. بڕیارە گرنگەکانی بەکارهێنەر
- **ڤیدیۆ نایەوێت** بۆ ئەم پرۆژانە، **تەنها وێنەی ڕاستەقینە و کۆتایی**، بە قەبارەی ڕاستەقینە و دابەزاندن.
- ڕەتی کردەوە: وێنەی تاقیکاری؛ دووبارەکردنەوەی هەمان وێنە (leossenas)؛ بیرۆکەی کلیشە.
- هەڵبژارد: «تۆڕی مۆلیدە» لە 10 بیرۆکەی نوێ؛ دواتر «سوارێک لەسەر ئەسپ و ڕمێک»، پاشان **«سوار بەبێ ئەسپ»**.
- 10 بیرۆکەی نوێ: ① تۆڕی مۆلیدە ② یەک دەفر بۆ ئاسمان ③ گوندی خنکاو ④ سێبەری درێژ ⑤ چایی هەورامان ⑥ بیرە ئەستێرەکان ⑦ ئاوێنەی تاکسی ⑧ شاری هەنار ⑨ تەنها یەک ژێ ⑩ شوێنپێی ڕووناک (هەستیار).
- پەیامی گەورە: بەکارهێنەر **ڕاستەقینەیی 100٪** دەوێت کە خەڵک پێیان وابێت وێنەی گیراوە.

## 5. ڕاستییەکان دەربارەی ئەنجام (ڕاستگۆیی)
- **«تۆڕی مۆلیدە»:** ئەگەری هەیە لە مۆبایلدا خەڵک بیباوەڕ بکەن؛ هونەرمەند وردەکارییەکان دەبینێت (خانووەکان زیاتر ڕێکن، وایەرەکان کەمێک ڕێکن).
- **«سوار»:** **بەکارهێنەر ڕەخنەی لێ گرت: لە وێنەی ڕاستەقینە ناچێت** (زەوی، بەرد، عەبا، دەست، هەیکەل، ئاگر، کەش). هۆکار: هەموو شتێک procedural ـە، هیچ تێکستچەر/مۆدێلی سکان‌کراو نییە، مانیکانی لەش سادەیە، دەست شاردراوەتەوە، پریشکی ئاگر یەکجۆرن، تەمەکە یەکسانە.
- مەزەندەی ڕاستگۆیانەی ڕاستەقینەیی: لێرە ~50–60٪؛ PC + MCP + سکان ~75–85٪؛ هونەرمەندی دەستی ~90–95٪؛ وێنەی ڕاستەقینە + Blender ~95٪+.
- پێشتر ئەمە بە بەکارهێنەر وترا: **ئەسپی ڕاستەقینە** نادروستێت بە کۆد؛ مۆدێلی سکان‌کراو یان وێنەی ڕاستەقینە پێویستە.

## 6. هەنگاوی داهاتوو (ئەوەی بەکارهێنەر پرسی)
بەکارهێنەر پرسی: **ئەگەر لەسەر PC بیکات، بە Blender MCP، چەند ڕاستەقینە دەبێت؟** وەڵام درا: PC + `blender-mcp` + Poly Haven/Sketchfab دەتوانێت **تێکستچەر و مۆدێلی سکان‌کراو** بهێنێت (باشترین سوود)، بەڵام ~95٪ ناگات چونکە Claude تەنها وێنەی رێندەر دەبینێت، نەک viewport. پێویستی PC: NVIDIA RTX 3060 8GB+، Blender 4.x، Claude Desktop، `blender-mcp`.
**ئەگەر بەکارهێنەر بیەوێت:** ڕێنمایی دامەزراندنی هەنگاو بە هەنگاو بدە، یان باشترە: بەکارهێنەر **وێنەی ڕاستەقینە** بگرێت و تەنها ئاگر/تەم/ڕووناکی/فینیشی فیلم بە Blender زیاد بکرێت.

## 7. ڕێنمایی بۆ Claude ـی داهاتوو
1. پێش هەر شتێک `git pull` بکە و `blender/` بخوێنەرەوە.
2. venv ـەکان دووبارە دروست بکەرەوە ئەگەر کۆنتەینەرەکە نوێ بێت (بڕوانە بەشی 1).
3. وێنەی گریدراو بە `.blend` بۆ PC لە `final/` و `*.blend` دا هەیە.
4. هەرگیز "%100 ڕاستەقینە" بەڵێن مەدە؛ ژمارەی ڕاستگۆ بدە.
5. هەر کارێکی نوێ: commit + push ی `blender/` (stop hook).
