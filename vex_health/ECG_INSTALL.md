# VEX Health — پێوانەی ECG (شاشەی ٢ چاوەڕێی پەنجە + شاشەی ٣ پێوانە)

## فایلە نوێیەکان (کۆپی بکە بۆ هەمان شوێن)
| فایل | چی دەکات |
|---|---|
| `lib/ecg/ecg_page.dart` | دیزاینی هەردوو شاشە + `openEcgPage()` |
| `lib/ecg/ecg_controller.dart` | فرمانی Band، حاڵەتەکان (waiting→measuring→done)، ٣٠ چرکە |
| `lib/ecg/ecg_signal.dart` | پڕۆسێسی شەپۆل: خەتی ڕاست، دۆزینەوەی پەنجە، BPM، کوالیتی |
| `tools/ecg_check/ecg_signal_test.py` | تێستی لۆجیک (Python) — ئارەزوومەندانە |

## فایلە گۆڕدراوەکان (فەرمان لە Band)
1. `lib/band/ble/vex_ble.dart` — لە `VexBand` دوو فەنکشن زیادکراوە: `startWaveform()` و `stopWaveform()`
   (دەنێرێت: measure HRV 50 چرکە + `ppgStream(true)`، وەک `PPGActivity` ی SDK ی فرۆشیار).
2. `lib/home/home_cards.dart` — `_tool(..., {VoidCallback? onTap})` و تایلی ECG: `onTap: openEcgPage`
   + `import '../ecg/ecg_page.dart';`

## بانگکردن لە هەر شوێنێکی تر
```dart
import 'ecg/ecg_page.dart';
openEcgPage();
```

## چۆن کار دەکات
- پەڕە کە دەکرێتەوە `EcgController.start()` فرمانی Band دەنێرێت و دەچێتە **شاشەی ٢**: خەتی ڕاستی ئەمبەر.
- کاتێک Band شەپۆل دەنێرێت و ئاماژە جێگیر بوو (پەنجە)، دوای ١ چرکە دەچێتە **شاشەی ٣**: شەپۆل بەپێی لێدانی دڵ دەجووڵێت، ژماردنەوەی ٣٠ چرکە.
- پەنجە لابرا ٣ چرکە ← دەگەڕێتەوە شاشەی ٢ (ژماردنەوە ڕادەوەستێت). ٩٠ چرکە بێ پەنجە ← سەرنەکەوتن + دووبارە.
- لە کۆتایی: BPM/HRV/سترێس لە ئەنجامی Band (ئەگەر هات) وەگیرێت، ئەگەر نا لە شەپۆلەکەوە.
- Debug تەنها: ئەگەر Band پەیوەست نەبێت، نموونەی دەستکرد پیشان دەدرێت (نیشانەی «نموونە»).

## تێبینی پێویست بۆ تێستی Band ی ڕاستەقینە (دەست پێوەنەگیراوە)
- `EcgSignal.invert` — ئەگەر شەپۆل پێچەوانەیە `true` بکە.
- `defaultRate = 50` — خۆی لە کاتی ڕاستەقینەوە دەخمڵێنرێت.
- `minStd = 0.8` (دۆزینەوەی پەنجە) و `ampFloor = 40` — بەپێی داتای ڕاستەقینە ڕێکبخە.
- ئەم شەپۆلە لە Band وە PPG ـە (یان ECG) — دەبێت لەسەر Band ی ڕاستەقینە پشتڕاست بکرێتەوە.
- بۆ بەکارهێنانی گشتی تەندروستییە، نەک دەستنیشانکردنی نەخۆشی.
