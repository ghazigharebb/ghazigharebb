# VEX Health — «Band لە دەستە یان نا» v4 (VEX Skin Sense v4 · PPG ی خاو)

ڕێک هەمان لۆجیکی پەڕەی تاقیکردنەوە (`tools/band_test/index.html`) کە لەسەر Band ی ڕاستەقینە (JCV8B CB6164) سەرکەوت.

## بۆچی v4
لۆگی Band ی ڕاستەقینە نیشانی دا:
- دڵی Band درۆ دەکات: لەسەر مێز ٣٠ چرکە «59» یان «76» ی جێگیر دەنێرێت ← ناتوانرێت بڕیاری لەسەر بدرێت.
- گەرمی زۆر هێواشە (~١° لە ٣٠ چرکەدا).
- شەپۆلی 0x07 (HRV) ٣٦ چرکە دوای دەستپێک دێت.
- **PPG ی خاو (0x78 ← پاکێتی 0x3a)** خێرا و ڕاستە: لەسەر پێست پاکێتی پاک هەر چرکەیەک؛ لابردن ← پاکێتی شێواو و پاشان Band خۆی ڕادەوەستێت؛ لەدەستکردنەوە ← Band خۆی دەست پێدەکاتەوە.

## یاساکان (`WearConfig` لە `lib/band/ble/vex_wear.dart`)
| | |
|---|---|
| پاکێتی 0x3a | ٣ بایت سەر + ٥٠ نموونە × ٤ بایت (big-endian) = ٥٠ Hz |
| پشکنین | ١٥ نموونەی کۆتایی: پاک = 300k–10M و گۆڕان < 2٪ · شێواو = لە دەرەوەی سنوور یان گۆڕان > 5٪ |
| **لە دەستە** | یەک پاکێتی پاک |
| **لە دەست نییە** | بێدەنگی ١٫٦ چرکە دوای شێواو / ٣ چرکە دوای پاک · یان ٣ شێواو بە دوای یەکدا · یان ٣٫٥ چرکە هیچ لە سەرەتاوە · یان شەحن |
| دووبارە ناردن | بێدەنگ ≥ ١٫٥ چرکە ← 0x78 هەر ٤ چرکە |
| دڵ | لە دۆخی 0x78 دا دڵی Band = 0 ← دڵ لە PPG (`PpgHeart`، ٥–٨ چرکە) تەنها کاتێک دڵنیایە |
| ECG / پێوانەی دەستی | PPG ی خاو ڕادەوەستێت (0x78 mode 3 + 5)، پاشان بەردەوام دەبێت |
| هاوکاتکردنی مێژوو | بڕیار نادرێت تا تەواو دەبێت |

ئەنجام لەسەر پاکێتە ڕاستەقینەکان: لابردن ٥٫٥ چرکە لە دەنگی ڕێنمایی (~٤ چرکە لە جووڵەی دەست)، لەدەستکردن ٥٫٨ چرکە (~٣ چرکە دوای ئەوەی Band دەست پێدەکاتەوە)، ٠ هەڵە لە کاتی لە دەستدا.
