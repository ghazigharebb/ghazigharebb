# VEX Health — کوردی بادینی (v2)

## دوو فایل بگۆڕە (جێگۆڕکێ بکە)
| فایل | شوێن |
|---|---|
| `lib/core/vx_bd.dart` | بزوێنەری وەرگێڕان: وشەی fallback + یاسای ڕێزمان + لۆگی debug |
| `lib/core/vx_bd_data.dart` | فەرهەنگ: ١٣٤١ وشە/ڕستە، ٦٣٠ دەقی تەواو، ١٢٨ قاڵب، ٣٠٣ خواردن، ٢٦٠ وشەی fallback |

هیچ شتێکی تر ناگۆڕدرێت؛ `kIsBd`، `VText`، `vxTr` هەر وەک خۆیان.

## چی چاک کرا
- ~٤٠٠ دەقی نوێ (BLE/Band، ECG، VitalAge، خێزان، خواردن، ڕێکخستن، سەرەتا…).
- وشەکانی سۆرانی کە لە فەرهەنگ نەبوون (ئەمڕۆ، ئاو، هەنگاو، هاوکات، چاودێری، ئامانج…) ئێستا بە یاسا دەگۆڕدرێن، نەک وەک سۆرانی بمێننەوە.
- «ئەمڕۆ→ئەڤرۆ، خەو→نڤستن، زۆر→گەلەک، دووبارە→جارەکا دی، هاوکات→هەڤدەم، شەوت باش→شەڤا تە باش، 22ی تشرینی یەکەم→22ێ تشرینا ئێکێ».
- پاشگرەکان: -کردن→-کرن ، -کردنەوە→-کرنەڤە ، ەکان/ەکە، ی→ێ.

## بۆ دۆزینەوەی دەقی ماوە (debug)
ئەپ لە debug دا هەر دەقێک کە وەرنەگێڕدرا یان بەشێکی سۆرانی مایەوە لە console دەنووسێت:
`BD-MISSING: <دەقەکە>`
زمان بکە بە بادینی، هەموو پەڕەکان بگەڕێ، لۆگەکە بۆ من بنێرە (یان `bdMissingWords()` بەکاربهێنە) و دەیانکەمە بادینی تەواو.

## بۆ دەستکاری
`tools/bd_tools/add1.py` و `add2.py`: لێرە وشەیەک بگۆڕە و `python3 gen.py` بکە، فایلی `vx_bd_data.dart` نوێ دەبێتەوە.
`port.py` = پۆرتی Python ی بزوێنەرەکە بۆ تێستکردنی خێرا.

## ئاگاداری
وەرگێڕانەکە لەلایەن منەوەیە و پێویستە کەسێکی بادینیخۆش بیخوێنێتەوە؛ ڕێنووس و وشە لەوانەیە لە شێوەزارەکەی تۆ جیاواز بن.
