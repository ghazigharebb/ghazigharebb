# زمانەکانی VEX Health — هەر زمانێک فایلی خۆی

| فایل | زمان | کۆد | ئاراستە |
|---|---|---|---|
| `lang_ckb_kurdish_sorani.dart` | کوردی سۆرانی (زمانی بنەڕەت) | `ckb` | RTL |
| `lang_kmr_kurdish_badini.dart` | کوردی بادینی | `kmr` | RTL |
| `lang_en_english.dart` | English | `en` | LTR |
| `lang_ar_arabic.dart` | العربية | `ar` | RTL |
| `lang_fa_persian.dart` | فارسی | `fa` | RTL |
| `lang_tr_turkish.dart` | Türkçe | `tr` | LTR |

## چۆن کار دەکات
- هەموو دەقەکانی ئەپ لە کۆدەکەدا بە **سۆرانی** نووسراون.
- کاتێک بەکارهێنەر زمانێک هەڵدەبژێرێت، `lib/core/vx_*.dart` خۆکارانە فایلی ئەو زمانە بەکاردەهێنێت و هەموو شاشەکان دەگۆڕێت (ئاراستەی RTL/LTR ـیش).
- شاشەی سەرەتا (هەڵبژاردنی زمان) لە `kReg..` ی هەر فایلێک دێت.

## گۆڕینی وەرگێڕانێک
لە فایلی زمانەکەدا تەنها بەهای دوای `:` بگۆڕە:
```dart
"دواتر": "Next",
```
کلیلە کوردییەکە (لای چەپ) دەستکاری مەکە. پیتی `$` بە شێوەی `\$` بنووسە.
