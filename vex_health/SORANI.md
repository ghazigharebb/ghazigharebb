# VEX Health — پشکنینی سۆرانی

پشکنینی ڕێنووس و ڕێزمان بۆ هەموو ١١٠٥ دەقی ستاتیکی و ١٢٩ قاڵبی گۆڕاو. هەڵە دۆزراوەکان لە سەرچاوە و لە داتای هەموو زمانەکان (en/kmr/ar/fa/tr) یەکسان چاککران:
- `ئاسایییە` ← `ئاساییە` (٢ دەق)
- `کاتژمێری لەرەر` ← `کاتژمێری لەرین`
- `ڕێپێدانی شوێن نەدرا` ← `ڕێگەپێدانی شوێن نەدرا`
- `بەم کاتی شەوە قورسە` ← `بەم کاتەی شەو قورسە`
- `ئەمڕۆ کەمی ڕۆیشتووە` ← `ئەمڕۆ کەم ڕۆیشتووە`
- `پەیوەستدەکرێت…` / `چالاکدەکرێت…` ← بە بۆشایی (`پەیوەست دەکرێت…`)
- `ماوە N هەنگاو تا ئامانج` ← `N هەنگاو ماوە تا ئامانج`

سنوور: ئەمە پشکنینی خۆمە نەک مامۆستای زمان؛ بەتایبەت دەقە تەندروستییەکان با کەسێکی کوردزان بیخوێنێتەوە. کۆدەکە هێشتا کۆمپایل نەکراوە.
