# VEX Plus — بەشداربوون و پارەدان (Flutter)

## فایلە نوێکان
- `lib/plus/plus_state.dart`  — دۆخی بەشداربوون (پلان، ماوە، تاقیکردنەوەی 7 ڕۆژ، دیاری Band) + `PlusPayment`
- `lib/plus/plus_page.dart`   — پەڕەی بەشداربوون: 1 / 6 / 12 مانگ، 50٪ داشکان، تایبەتمەندییەکان، پارەدان، سەرکەوتن/شکست

## فایلە گۆڕدراوەکان
- `lib/main.dart`                      — `await PlusState.I.load();`
- `lib/band/band_state.dart`           — کاتی یەکەم پەیوەستکردنی Band: 6 مانگ Plus بە خۆڕایی (یەک جار)
- `lib/onboarding/profile_page.dart`   — کارتی «VEX Plus» لە پڕۆفایل

## نرخەکان (د.ع)
| پلان | پێش داشکان | دوای 50٪ |
|---|---|---|
| 1 مانگ | 10,000 | 5,000 |
| 6 مانگ | 50,000 | 25,000 |
| 12 مانگ | 100,000 | 50,000 |
بۆ گۆڕینی نرخ: `kPlusPlans` لە `plus_state.dart`.

## بەکارهێنان
```dart
PlusPage.open();                              // کردنەوەی پەڕەکە
PlusPage.open(title: 'سکانی AI ی بێسنوور',     // لەگەڵ ناونیشانی تایبەت
              desc: 'ئەمڕۆ 3 سکانی خۆڕاییت بەکارهێنا.');
if (PlusState.I.isPro) { ... }                // ئایا بەشدارە؟
```

## پارەدانی ڕاستەقینە (گرنگ)
ئێستا `PlusPayment.charge` دیمۆیە (1.5 چرکە، هیچ پارە ناڕوات). بۆ FIB / FastPay / ZainCash / Qi Card:
```dart
PlusPayment.charge = (method, plan) async {
  // 1) داوای پارەدان لە سێرڤەرەکەت بنێرە  2) چاوەڕێی پشتڕاستکردنەوە بکە
  // true = پارە وەرگیرا، false = سەرنەکەوت
};
```
- کلیلی API ی دەرگای پارەدان تەنها لەسەر سێرڤەر بێت، هەرگیز لە ئەپەکە نا.
- چالاککردنی Plus لەسەر سێرڤەریش پشتڕاست بکەرەوە (نەک تەنها `SharedPreferences`).
- Google Play / App Store: ئەگەر ئەپەکە لەوێ بڵاو دەکەیتەوە، بەشداربوونی دیجیتاڵ دەکرێت پێویستی بە سیستەمی کڕینی ناو-ئەپی ئەوان بێت.

## تێبینی
- فیچەرەکان (سکان، VEX AI …) هێشتا بە `PlusState.I.isPro` نەبەسترێنەوە ئەگەر پێشتر نەتکردووە. ئەم پەڕەیە بەشداربوونەکە بەڕێوە دەبات.
- پشکنین: تەنها syntax کرا. `flutter pub get` و `flutter analyze` بکە.
