# ئاگادارکەرەوەی Band — کاتژمێر · کاتی وەرزش · کاتەکانی نوێژ

لە پەڕەی «پڕۆفایل» ← بەشی **ئاگادارکەرەوەی Band (لەرین)**.

| بەش | چی دەکات |
|---|---|
| ⏰ کاتژمێری لەرین | کاتی 12 کاتژمێری (`6:43 PM`)، ناو، هەتا ٨ کاتژمێر، هەموو ڕۆژێک |
| ⏱️ کاتی وەرزش | کەمبوونەوە بە `کاتژمێر:خولەک:چرکە.میلی چرکە`، ڕاگرتن/بەردەوامبوون/سفرکردنەوە، دوگمەی +/− دابگرە بۆ خێراتر |
| 🕌 کاتەکانی نوێژ | ئارەزوومەندانە؛ هەر نوێژێک بە جیا؛ لە کاتی بانگ یان 5/10/15 خولەک پێش بانگ |

## کاتەکانی بانگ — IslamicFinder
- سەرچاوە: `https://www.islamicfinder.org/world/iraq/95446/erbil-prayer-times/` (هەولێر).
- ئەپ خشتەی مانگەکەی پەڕەکە دەخوێنێتەوە (`lib/alerts/prayer_site.dart`) و لە ئامێر هەڵیدەگرێت؛ هەر 12 کاتژمێر جارێک نوێ دەبێتەوە (یان دوگمەی «↻ نوێکردنەوە»).
- **پاراستن:** ئەگەر ڕۆژێک لەگەڵ ژماردنی ناوخۆیی زیاتر لە 6 خولەک جیاواز بوو (واتە پەڕەکە گۆڕاوە یان شی کردنەکە هەڵەیە) ڕەت دەکرێتەوە. بەم شێوەیە کاتی هەڵە هەرگیز نیشان نادرێت.
- ئەگەر ئینتەرنێت نەبوو یان سایتەکە بەردەست نەبوو: **ژماردنی ناوخۆیی** (`prayer_calc.dart`) — هەمان ڕێگا: Muslim World League (فەجر 18°، عیشا 17°)، عەسری شافیعی. لەگەڵ خشتەی IslamicFinder بۆ ئۆکتۆبەری 2026 بەراورد کراوە: ~90% هەمان خولەک، زۆرترین جیاوازی 1 خولەک.
- شارەکانی تر (سلێمانی، دهۆک، کەرکووک، بەغدا…) و «شوێنی ئێستا» (GPS) ژماردنی ناوخۆیین، چونکە تەنها ناونیشانی هەولێرمان لە IslamicFinder هەیە. بۆ زیادکردنی شارێکی تر: ناونیشانی پەڕەکەی و لەناو `IslamicFinder.fetchMonth` بیگۆڕە.

## چۆن کار دەکات
1. ئەپ کراوە: کاتژمێرێکی ناوخۆیی هەر چرکەیەک دەپشکنێت ← مۆبایل دەلەرێتەوە + پەنجەرەی «ڕاگرتن» (60 چرکە دواتر خۆی دادەخرێت).
2. ئەپ داخراوە: هەمان کاتەکان وەک ئاگادارکردنەوەی خشتەکراوی سیستەم تۆمار دەکرێن (کاتژمێر 7 ڕۆژ، نوێژ 3 ڕۆژ، کاتی وەرزش) و لە هەر کردنەوەیەکی ئەپ نوێ دەکرێنەوە. دوای ڕیستارتی مۆبایل (Android) دەمێننەوە.
3. **لەرینی خودی Band:** `BandLink` (`lib/alerts/band_alerts.dart`) پردێکی `MethodChannel('vex/band')` ـە بە دوو فەرمان: `vibrate` و `syncAlerts`. ئەگەر لای ناتیڤ جێبەجێ نەکرابێت، بێدەنگ پشتگوێ دەخرێت و مۆبایلەکە دەلەرێتەوە. پێویستە کۆدی BLE ی Band لەم دوو فەرمانە بنووسرێت (پڕۆتۆکۆڵی Band لای من نییە).

## دامەزراندن
```bash
flutter pub get
python3 tools/setup_native.py        # مۆڵەت و وەرگرەکانی Android دەخاتە manifest
```
### Android — desugaring (پێویستە بۆ flutter_local_notifications)
`android/app/build.gradle(.kts)`:
```gradle
android {
    compileOptions {
        coreLibraryDesugaringEnabled true
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8
    }
}
dependencies {
    coreLibraryDesugaring 'com.android.tools:desugar_jdk_libs:2.0.4'
}
```
(لە `.kts`: `isCoreLibraryDesugaringEnabled = true` و `coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.0.4")`). `compileSdk` دەبێت 34 یان زیاتر بێت.

### iOS
- `native/ios/Info_plist_additions.xml` ← ناو `Info.plist` (مۆڵەتی شوێن زیاد کراوە).
- `native/ios/Runner/AppDelegate_snippet.swift` ← دێڕی `UNUserNotificationCenter.current().delegate` بخەرە ناو `AppDelegate.swift`.
- iOS تەنها دەنگی ئاگادارکردنەوە دەدات؛ ناتوانێت لەرینی تایبەت بۆ ئەپ دیاری بکات. لەرینی Band لە ڕێگای BLE ـەوە دێت.
- iOS تەنها 64 ئاگادارکردنەوەی خشتەکراو قبوڵ دەکات؛ ئەپ خۆی لە 60 تێپەڕ ناکات.
