# ڕێکخستنی ئەندرۆید و ئایفۆن

## Android
1. `android/app/build.gradle` (یان `.kts`): `minSdk` دەبێت **٢١** یان زیاتر بێت (flutter_inappwebview ی پێویستە).
2. `android/app/src/main/AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.CAMERA"/>
<application
    android:networkSecurityConfig="@xml/network_security_config"
    ... >
```
3. فایلی نوێ `android/app/src/main/res/xml/network_security_config.xml` (ئەگەر فۆڵدەری `xml` نییە، دروستی بکە):
```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
    <domain-config cleartextTrafficPermitted="true">
        <domain includeSubdomains="false">localhost</domain>
        <domain includeSubdomains="false">127.0.0.1</domain>
    </domain-config>
</network-security-config>
```
بێ ئەمە، پەڕەکە وەک شاشەی سپی دەمێنێتەوە (چونکە سێرڤەری ناوخۆیی `http://localhost:8765` ـە).

## iOS
`ios/Runner/Info.plist` — ناو `<dict>`:
```xml
<key>NSCameraUsageDescription</key>
<string>بۆ سکانکردنی خواردن</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>بۆ هەڵبژاردنی وێنەی خواردن</string>
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsLocalNetworking</key>
    <true/>
</dict>
```
هەروەها `ios/Podfile`: `platform :ios, '12.0'` (یان زیاتر).
